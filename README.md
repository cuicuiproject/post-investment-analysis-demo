# 投后分析系统 · 对内演示版

单文件 HTML 原型（`index.html`），无需依赖、无需构建，双击即可在浏览器打开。用于向内部技术说明页面结构、模块划分与交互口径。

- 数据：全部为**演示数据**，不含真实客户持仓
- 形态：纯静态单页，原生 HTML + CSS + JavaScript（含内联 SVG 图表）
- 适配：Chrome / Edge 最新版；建议 1400px 以上宽度

## 页面模块

| 分组 | 页面 | 说明 |
| --- | --- | --- |
| 专户汇总 | 委外账户 | 跨专户账户口径汇总 |
| 专户汇总 | 基金收益 | 按基金维度汇总持仓规模与收益 |
| 专户汇总 | 债券分析 | 跨专户直接持有债券，支持列表/图表视图 |
| 专户汇总 | 股票分析 | 穿透后股票持仓，支持行业筛选、搜索、点击行查看产品分布 |
| 专户分析 | 专户列表 | 8 只专户的净值、收益与数据时效 |
| 专户分析 | 专户详情 | 专户持仓、基金、交易明细（V3 版） |
| 数据与配置 | 上传数据 | 估值表 / 交易流水上传与校验流程 |
| 数据与配置 | 上传历史 | 按专户查询上传记录与处理状态 |
| 数据与配置 | 专户管理 | 专户代码、名称、产品类型（委外/通道，选填）、别名、估值日历维护 |
| 数据与配置 | 业绩基准 | 基准曲线与参数维护 |

## 本期范围说明

- **经营分析模块本期不提供，下期上线。** 原经营总览、理财产品穿透、投资策略分析、管理主体分析四个页面的代码仍保留在文件中，由 `index.html` 头部的开关统一控制：

  ```html
  <script>window.OPS_MODULE_ENABLED=false;</script>
  ```

  改为 `true` 即可恢复侧边栏入口、页面与默认落地页，便于下期直接续接，无需重新合并代码。
- **股票分析**页已按最新口径精简：去掉「行业暴露」「收益贡献」两个侧栏卡片与「占产品 AUM」指标，主表改为单列铺满。
- **专户管理**新增「产品类型」字段（委外 / 通道，可不选），用于在委外账户分析中区分专户归属：委外账户页可按产品类型筛选，账户名称下方同步显示类型标注；未设置时按「未设置」展示，不参与委外/通道筛选。
- 默认落地页为「专户分析 / 专户列表」。
